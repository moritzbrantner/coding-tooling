A zero-install, deterministic first pass over public repositories. By default the page ranks recent repositories without a token, then inspects bounded open pull requests and issues in the suggested repository before handing off to repository preflight.

Remote preflight is intentionally narrower than the local coding-tooling CLI.

Repository ranking uses bounded anonymous GitHub metadata: recent repository activity, the combined open issue/pull-request count, and source-versus-fork status. It selects a starting repository without claiming roadmap priority.

Ranking uses item recency plus a modest preference for in-flight pull requests and ready-for-review work. The two highest-ranked pull requests get bounded observed CI evidence; CI does not affect ranking, and required-check status, roadmap priority, and dependencies are not inferred.
